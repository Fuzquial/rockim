## A — loi de joint et relais (rapport brut, puis ma relecture)

1. [BLOQUANT] `Fdem3dSolver.cpp:4429/4443/4458`, `FdemSolver.cpp:6017/6046` — sous `jointElastic =
   parabolic` la loi transmet 2·pj·dn en compression, mais s_E, la plage coulomb et l'amorçage du DIF
   lisent `J.pj * dn` : **σ_n divisé par deux** dans tout ce qui fixe une résistance de mode II (le cap
   τ_lim, lui, lit la vraie contrainte `sig`). Solidity lit la vraie contrainte (σ_tmp = pe·o/el).
   → clé `jointNormalProxy = penalty | law` (défaut penalty = bit-identique ; law = pjC·dn).
2. [IMPORTANT] `:2651-2660` — DIF continu : `setJointLengths` réécrit dnE, dnF, slipF à chaque pas,
   les moteurs rn, rs changent de référence sous un D acquis ; l'énergie dissipée n'est plus G_f.
   → clé `difLengths = live | frozen`.
3. [IMPORTANT] `:4546, :4562`, 2D `:6187` — dashpot `jointXi` et etaN/etaS lisent la vitesse de la
   paire de sommets sous midedge (la loi lit l'arête) ; dampW faux. Inerte sur nos decks (jointXi 0).
4. [IMPORTANT] `:4639`, 2D `:6347` — le ratchet `ksr` peut se figer à la naissance d'un joint inséré
   sous traction (smx > 0 dès le premier pas, τ_lim petit) → interface sans raideur tangentielle.
   → n'armer le ratchet de mode II qu'une fois le cap actif (tauEnv < pj·smx).
5. [IMPORTANT → NON RETENU] `slipRef` : numérateur |s_p| sans −s_E sur plastic. Relecture : s_p ne
   s'accumule qu'au-delà du seuil (retour radial), donc |s_p| ≡ (s_max − s_E) de la branche origin ;
   les deux branches ont le même glissement critique. Écart documenté, pas de code.
6. [IMPORTANT] `:5227-5233` — `relay` ne fait que la moitié de D4 : les paires sans joint mort gardent
   la rampe relaxée (vRef *= relax_), pas l'offset figé. → `gcBirthTau = 0` = offset figé (à coder
   quand relay sera mesuré).
7. [IMPORTANT] `:5211-5226, :5240` — le calage du relais n'est pas mesuré : fnC pris au premier pas de
   recouvrement (quasi nul) → facteur saturé à 3 ; cplDf appliqué après. → deliveredSum_/targetSum_.
8. [IMPORTANT] `relay` absent en 2D (3D seul, documenté ainsi).
9. [IMPORTANT → FAUX] « frottement de joint absent chez Solidity » : leur f_s = c − tanφ·σ_tmp est la
   RÉSISTANCE dès z = 1 (frottement compris) ; `dpefm = 0` est le résiduel après z → 0. Le défaut
   rockim (frottement plein dès D = 0) est conforme ; `jointFrictionMobilised = damage` s'en
   éloignerait. Pas de changement.
10. [IMPORTANT → NON RETENU] facteur 2 sur op/sp : sous la correspondance pj = pe/(2 el) choisie
    (pente 2pj à l'origine = pe/el), dnE = ft/pj = 2 el ft/pe = op, et dnF = op + max(2 op, 3Gf/ft),
    plancher slipF = sp : la convention est reproduite. Reste le choix pf 20 vs 26,32 (deck).
11-15. [MINEUR] reprojection de slip non dissipative (θ²), dampW capte l'écrêtage, deux règles
    midedge 2D/3D, amorçage DIF sur sommets sous midedge, bannière du ratchet muette sur ses chemins

Vérifiés sains : slipRef bit-identique clé absente ; knr ; compteurs relay en zone série ; pas de
